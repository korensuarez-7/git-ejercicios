# 03 · Condicionales

**Temas:** `if`, `elif`, `else`, operadores de comparación (`== != > < >= <=`), operadores lógicos (`and`, `or`, `not`), condicionales anidados.

**Ejercicios sugeridos**
1. Decir si una persona es mayor o menor de edad.
2. Pedir una nota (0.0 a 5.0) y decir si aprobó (>= 3.0).
3. Decir cuál de tres números es el mayor.
