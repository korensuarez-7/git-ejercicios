# 06 · Funciones

**Temas:** `def`, parámetros, valores por defecto, `return`, alcance de variables, importar funciones de otro archivo.

**Ejercicios sugeridos**
1. Función `es_par(numero)` que devuelva `True` o `False`.
2. Reescribir la calculadora usando una función por operación.
3. Función que reciba una lista y devuelva el mayor y el menor.
