# 02 · Strings

**Temas:** comillas, concatenación, `len()`, índices, slicing `[inicio:fin:paso]`, f-strings, métodos (`upper`, `lower`, `replace`, `split`, `strip`).

**Ejercicios sugeridos**
1. Pedir una palabra y mostrarla al revés (`[::-1]`).
2. Contar cuántas vocales tiene una frase.
3. Pedir nombre completo y mostrar las iniciales.
