# 05 · Listas, tuplas y diccionarios

**Temas:** crear y recorrer listas, `append`, `remove`, `sort`, tuplas, diccionarios (clave: valor), `.keys()`, `.values()`, `.items()`.

**Ejercicios sugeridos**
1. Guardar 5 notas en una lista y calcular el promedio.
2. Agenda de contactos con un diccionario (nombre → teléfono).
3. Lista de compras: agregar, eliminar y mostrar productos.
